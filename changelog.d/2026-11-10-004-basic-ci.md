# Basic CI for backend, frontend and AI service
- Type: infra
- Area: repo
- Commit: see `git log --grep "Add basic CI"`

## Why
No automated checks existed; nothing told us when a change broke a build.

## What changed
- New `.github/workflows/ci.yml`, runs on every push and pull request, 3 independent jobs:
  - **backend**: Java 17, `./mvnw -B test` (unit tests; context-load test excluded
    because it needs a live database).
  - **frontend**: Node 22, `npm ci`, `npm run lint`, `npm run build`.
  - **ai-service**: Python 3.11, `pip install -r requirements.txt`, import check of `app.py`
    (lists routes; the embedding model is not downloaded).
- No deploy, no secrets, no services.

## How to test
Ran the same commands locally on 2026-11-10: backend tests pass (incl. new
`JobPostingServiceAccessTest`), frontend lint clean + build OK, AI import OK.
On GitHub it runs only after a push (not pushed yet — needs owner consent).

## Risk / rollback
CI only; does not affect the app. Delete the workflow file to undo.
